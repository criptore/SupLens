# Security policy

## Reporting a vulnerability in SupLens

Please **do not open a public issue**. Use GitHub's private vulnerability reporting instead:
go to the **Security** tab of this repository and click **Report a vulnerability**.

You should get a first answer within 7 days. Once a fix is released, we are happy to credit you.

## Reporting a malicious package

SupLens is not a registry. If you found a malicious npm package, report it to npm
(<https://www.npmjs.com/support>) and to the package maintainer. You can also send it to us
privately through the same channel so we can add it to our test cases.

## Supported versions

SupLens is pre-alpha: only the latest commit on `main` is supported.
